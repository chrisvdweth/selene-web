# SELENE — Lunar Lab Brand Kit

## Brand idea

Lunar Lab makes AI learning feel like opening a well-prepared notebook: inspect the concept, see its dependencies, launch it, and change inputs.

## Voice

Direct, precise, calm, encouraging. Prefer active verbs: **Explore**, **Inspect**, **Run**, **Compare**, and **Continue**. Avoid gatekeeping and generic productivity language.

## Typography

- Display: Space Grotesk, 600
- Interface/body: Inter, 400–600
- Code/data: IBM Plex Mono, 500

Three faces, six weights between them, and no weight is loaded that no rule
asks for. Every bold run in the interface is pinned to 500 or 600 rather than
inheriting the browser's 700, so the vendored Inter axis stops at 600.

### The faces are self-hosted, and that is not a detail

They arrive from this origin, as woff2, from `src/styles/fonts/`, generated by
`node scripts/fetch-fonts.mjs` and committed. They are **not** loaded through
`@import url("https://fonts.googleapis.com/css2?...")`, which is what an earlier
pass did and what this note exists to prevent recurring.

That form of loading is wrong twice over. A CSS `@import` of a remote sheet is
render-blocking, and it serialises: the browser must fetch the page's stylesheet,
discover the `@import`, resolve and fetch `fonts.googleapis.com`, and only then
learn which files to fetch from `fonts.gstatic.com`. Two extra hosts, two extra
round trips, and no text on screen until both answer. It also hands every
visitor's IP address to a third party from a site that makes no other external
request at all — measured, not assumed: `design-review/no-3p.mjs` walks all eight
routes in both themes and reports zero foreign requests.

The rules therefore are:

- Faces are same-origin. If a face cannot be self-hosted, it is not used; the
  fallback is the system stack, not a remote sheet.
- Every face carries `font-display: swap`. Text paints in the fallback at once.
- Every face keeps its `unicode-range`. The `latin-ext` slices are committed but
  only travel when an extended glyph actually appears, which is why keeping them
  costs nothing on a normal page and saves a face-swap mid-word on names like
  Kullback–Leibler.
- Inter is requested as one variable `wght@400..600` file, not as three named
  weights. Google serves the same variable bytes for each named weight, so the
  naive request shipped the identical 48KB latin file three times.
- OFL 1.1 requires the licence travel with the binaries: `src/styles/fonts/OFL.txt`.

The rendered notebook HTML is a separate document, so it repeats the `@font-face`
block with the URLs repointed at copies the renderer places beside the pages
(`/notebooks/fonts/`). A topic page therefore fetches the latin faces twice —
once hashed for the shell, once unhashed for the frame, about 76KB, cached from
then on across all 82 dossiers. That duplication is the price of keeping the
committed faces in `src/` where the bundler can hash them; it is bounded,
same-origin, non-blocking, and strictly cheaper than the two third-party round
trips it replaced.

## Interface principles

- A local dependency workbench replaces an overwhelming global graph.
- The active notebook is always an explicit next action.
- Use 12px cards, 8px controls, thin rules, and restrained elevation.
- No decorative gradients; information should feel measured and runnable.
- All interaction has visible focus, a text alternative, and a mobile equivalent.

## Detector exception

The Impeccable detector flags Inter and Space Grotesk under `overused-font`
(four findings in `src/styles/fonts/fonts.css`). The exception is deliberate:
both faces are pinned by this brand kit, and the skill's own rule is that a
clear brief outranks a saturated-pattern warning. Distinctiveness is earned
through restraint rather than novelty — Space Grotesk appears only at 600 for
display, Inter's axis is capped at 600 so nothing inherits a browser 700, and
IBM Plex Mono carries every measured value, identifier and record. All three are
self-hosted as latin/latin-ext woff2 subsets with `font-display: swap`; no
request leaves the origin. Do not swap the faces to silence the rule; if the
identity is ever reopened, replace this note with the new decision.
