The Linear Layer

The linear layer, often referred to as a fully connected or affine layer, is one of the most fundamental components in neural networks. At its core, a linear layer applies a simple mathematical operation: it multiplies an input vector or matrix by a weight matrix and then adds a bias term. Despite this apparent simplicity, this operation provides the essential mechanism by which neural networks transform and combine features across layers, enabling the model to represent increasingly abstract patterns in the data.

Because of this role, linear layers form the backbone of virtually all neural network architectures. From multilayer perceptrons to convolutional neural networks, recurrent networks, and modern transformer-based models, linear layers are used to project inputs into new feature spaces, mix information across dimensions, and map hidden representations to outputs. Nonlinear activation functions often receive most of the attention, but without linear layers there would be no learnable structure for these nonlinearities to act upon. Understanding linear layers is therefore equivalent to understanding the structural "skeleton" of neural networks.

This notebook places a strong emphasis on the mathematical foundations of the linear layer, with particular focus on how gradients are computed during backpropagation. Rather than treating gradient computation as a black box handled by automatic differentiation, we derive the partial derivatives with respect to inputs, weights, and biases step by step. This mathematical perspective clarifies how errors flow backward through a network and how each parameter contributes to the final loss, which is crucial for building intuition about learning dynamics and debugging models in practice.

By avoiding high-level deep learning frameworks, the implementation exposes every operation involved in training, making the relationship between the equations and the code explicit. This hands-on approach reinforces the mathematical concepts and demonstrates how backpropagation is realized in actual software.

Forward Pass

In a neural network, the forward pass is the process of computing the output of the network for a given input. Starting from the input layer, data is passed sequentially through each layer, with each layer's output becoming the input to the next layer. The forward pass continues until the final layer produces the network's prediction or output. This output is then used to compute a loss L\mathcal{L}L value by comparing it to the ground truth provided by the annotated training dataset. Importantly, the forward pass defines how information flows through the model and establishes the intermediate values that are later needed during the backward pass to compute gradients for learning.

The operation each neuron of a linear layer performs during the forward pass is to compute the weighted sum of the input features plus a bias. More concretely, for a single (i.e., unbatched) input vector xi∈RDx{i} \in \mathbb{R}^Dxi∈RD, the kkk-th neuron computes:

yik=wk⊤xi+bk\large y{ik} = \mathbf{w}k^\top \mathbf{x}{i} + bk yik=wk⊤xi+bk

where xi=[xi1,xi2,…,xiD]⊤\mathbf{x}i = [x{i1}, x{i2}, \dots, x{iD}]^\topxi=[xi1,xi2,…,xiD]⊤ is the input vector of size DDD, and wk=[w1k,w2k,…wDk]\mathbf{w}k = [w{1k}, w{2k},\dots w{Dk}]wk=[w1k,w2k,…wDk] is the weight vector associated with that kkk-th neuron and bkbkbk is its bias. Each neuron therefore produces one scalar output that represents how strongly the input aligns with its learned weight vector, shifted by the bias.

In practice, we compute the forward pass for all neurons and with respect to all inputs in a batch in parallel. We can express this computation using the following matrix notations, each of the components we have already defined:

Broadcasting means that the bias vector b\mathbf{b}b is conceptually replicated NNN times, once for each sample in the batch, so that it can be added element-wise to XW\mathbf{XW}XW. Backward Pass

In a neural network, the process of computing gradients of the loss with respect to the model's parameters and intermediate activations (i.e., the outputs of previous layers) as called the backward pass. Starting from the loss at the output layer, gradients are propagated backward through the network using the chain rule of calculus. During the backward pass, each layer determines how much it contributed to the final error by computing gradients with respect to its weights, biases, and inputs. These gradients are then used by an optimization algorithm (such as gradient descent) to update the parameters, enabling the network to learn from data.

In the following, we assume that our linear layer is some layer in the network — that is; it received its input X\mathbf{X}X as the output from a previous layer and passed its output Y\mathbf{Y}Y to a subsequent layer. The latter assumes that during the backward pass through the linear layer, the upstream gradient ∂L∂Y\frac{\partial \mathcal{L}}{\partial \mathbf{Y}}∂Y∂L​ has been computed.

Since loss L\mathcal{L}L is a scaler and Y\mathbf{Y}Y is matrix of shape N×MN\times MN×M, the gradient ∂L∂Y\frac{\partial \mathcal{L}}{\partial \mathbf{Y}}∂Y∂L​ will also have a shape of N×MN\times MN×M, with each element of ∂L∂Y\frac{\partial \mathcal{L}}{\partial \mathbf{Y}}∂Y∂L​ being the derivative of L\mathcal{L}L with respect to one element in Y\mathbf{Y}Y. In other words, ∂L∂Y\frac{\partial \mathcal{L}}{\partial \mathbf{Y}}∂Y∂L​ is the Jacobian matrix (or just Jacobian), i.e., the matrix of all first-order partial derivatives of a function with multiple inputs and multiple outputs. ∂L∂x11 =∂L∂y11w11+∂L∂y12w12+∂L∂y13w13∂L∂x12 =∂L∂y11w21+∂L∂y12w22+∂L∂y13w23∂L∂x21 =∂L∂y21w11+∂L∂y22w12+∂L∂y23w13∂L∂x22 =∂L∂y21w21+∂L∂y22w22+∂L∂y23w23 \begin{align} \large\frac{\partial \mathcal{L}}{\partial x{11}}\ &\large= \frac{\partial\mathcal{L}}{\partial y{11}}w{11} + \frac{\partial\mathcal{L}}{\partial y{12}}w{12} + \frac{\partial\mathcal{L}}{\partial y{13}}w{13}\\[1em] \large\frac{\partial \mathcal{L}}{\partial x{12}}\ &\large= \frac{\partial\mathcal{L}}{\partial y{11}}w{21} + \frac{\partial\mathcal{L}}{\partial y{12}}w{22} + \frac{\partial\mathcal{L}}{\partial y{13}}w{23}\\[1em] \large\frac{\partial \mathcal{L}}{\partial x{21}}\ &\large= \frac{\partial\mathcal{L}}{\partial y{21}}w{11} + \frac{\partial\mathcal{L}}{\partial y{22}}w{12} + \frac{\partial\mathcal{L}}{\partial y{23}}w{13}\\[1em] \large\frac{\partial \mathcal{L}}{\partial x{22}}\ &\large= \frac{\partial\mathcal{L}}{\partial y{21}}w{21} + \frac{\partial\mathcal{L}}{\partial y{22}}w{22} + \frac{\partial\mathcal{L}}{\partial y{23}}w{23} \end{align} ∂x11∂L​ ∂x12∂L​ ∂x21∂L​ ∂x22∂L​ ​=∂y11∂L​w11+∂y12∂L​w12+∂y13∂L​w13=∂y11∂L​w21+∂y12∂L​w22+∂y13∂L​w23=∂y21∂L​w11+∂y22∂L​w12+∂y23∂L​w13=∂y21∂L​w21+∂y22∂L​w22+∂y23∂L​w23​​

We can take all for expressions and actually place them into the Jacobian ∂L∂X\frac{\partial \mathcal{L}}{\partial \mathbf{X}}∂X∂L​:

∂L∂X =[∂L∂x11∂L∂x12∂L∂x21∂L∂x22]=[∂L∂y11w11+∂L∂y12w12+∂L∂y13w13∂L∂y11w21+∂L∂y12w22+∂L∂y13w23∂L∂y21w11+∂L∂y22w12+∂L∂y23w13∂L∂y21w21+∂L∂y22w22+∂L∂y23w23] \begin{align} \large\frac{\partial \mathcal{L}}{\partial \mathbf{X}}\ &\large= \begin{bmatrix} \frac{\partial\mathcal{L}}{\partial x{11}} &\frac{\partial\mathcal{L}}{\partial x{12}}\\ \frac{\partial\mathcal{L}}{\partial x{21}} & \frac{\partial\mathcal{L}}{\partial x{22}} \end{bmatrix}\\[1em] &\large = \begin{bmatrix} \frac{\partial\mathcal{L}}{\partial y{11}}w{11} + \frac{\partial\mathcal{L}}{\partial y{12}}w{12} + \frac{\partial\mathcal{L}}{\partial y{13}}w{13} & \frac{\partial\mathcal{L}}{\partial y{11}}w{21} + \frac{\partial\mathcal{L}}{\partial y{12}}w{22} + \frac{\partial\mathcal{L}}{\partial y{13}}w{23}\\ \frac{\partial\mathcal{L}}{\partial y{21}}w{11} + \frac{\partial\mathcal{L}}{\partial y{22}}w{12} + \frac{\partial\mathcal{L}}{\partial y{23}}w{13} & \frac{\partial\mathcal{L}}{\partial y{21}}w{21} + \frac{\partial\mathcal{L}}{\partial y{22}}w{22} + \frac{\partial\mathcal{L}}{\partial y{23}}w{23} \end{bmatrix} \end{align} ∂X∂L​ ​=[∂x11∂L​∂x21∂L​​∂x12∂L​∂x22∂L​​]=[∂y11∂L​w11+∂y12∂L​w12+∂y13∂L​w13∂y21∂L​w11+∂y22∂L​w12+∂y23∂L​w13​∂y11∂L​w21+∂y12∂L​w22+∂y13∂L​w23∂y21∂L​w21+∂y22∂L​w22+∂y23∂L​w23​]​​

As the last step — just by looking at it hard enough — we can decompise ∂L∂X\frac{\partial \mathcal{L}}{\partial \mathbf{X}}∂X∂L​ into a product of the upstream gradient ∂L∂Y\frac{\partial \mathcal{L}}{\partial \mathbf{Y}}∂Y∂L​ and the transpose of the weight matrix W\mathbf{W}W:

∂L∂X =[∂L∂y11∂L∂y12∂L∂y13∂L∂y21∂L∂y22∂L∂y23][w11w21w12w22w13w23]=∂L∂YW⊤ \begin{align} \large\frac{\partial \mathcal{L}}{\partial \mathbf{X}}\ &\large= \begin{bmatrix} \frac{\partial\mathcal{L}}{\partial y{11}} & \frac{\partial\mathcal{L}}{\partial y{12}} & \frac{\partial\mathcal{L}}{\partial y{13}}\\ \frac{\partial\mathcal{L}}{\partial y{21}} & \frac{\partial\mathcal{L}}{\partial y{22}} & \frac{\partial\mathcal{L}}{\partial y{23}} \end{bmatrix} \begin{bmatrix} w{11} & w{21} \\ w{12} & w{22} \\ w{13} & w{23} \\ \end{bmatrix}\\[1em] &\large = \frac{\partial \mathcal{L}}{\partial \mathbf{Y}}\mathbf{W}^\top \end{align} ∂X∂L​ ​=[∂y11∂L​∂y21∂L​​∂y12∂L​∂y22∂L​​∂y13∂L​∂y23∂L​​]​w11w12w13​w21w22w23​​=∂Y∂L​W⊤​​

In short, we can compute the gradients ∂L∂X\large\frac{\partial \mathcal{L}}{\partial \mathbf{X}}∂X∂L​ simply by multiplying the upstream gradient ∂L∂Y\frac{\partial \mathcal{L}}{\partial \mathbf{Y}}∂Y∂L​ from the subsequent layer (with respect to the forward pass) and the transpose of the weight matrix W\mathbf{W}W of the linear layer.

Side note: Recall that the full Jacobian matrix ∂Y∂X\frac{\partial\mathbf{Y}}{\partial\mathbf{X}}∂X∂Y​ would have N2⋅N⋅DN^2 \cdot N\cdot DN2⋅N⋅D elements. More specifically, ∂Y∂X\frac{\partial\mathbf{Y}}{\partial\mathbf{X}}∂X∂Y​ would have the following block-diagonal structure, where each block corresponds to one sample in the batch. There are NNN diagonal blocks, one per input sample, and each block has shape M×DM\times DM×D and is exactly the weight matrix W⊤\mathbf{W}^\topW⊤. All off-diagonal blocks are zero matrices.

∂Y∂X=[W⊤0⋯00W⊤⋯0⋮⋮⋱⋮00⋯W⊤]\large \frac{\partial\mathbf{Y}}{\partial\mathbf{X}} = \begin{bmatrix} \mathbf{W}^\top & 0 & \cdots & 0 \\ 0 & \mathbf{W}^\top & \cdots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \cdots & \mathbf{W}^\top \end{bmatrix} ∂X∂Y​=​W⊤0⋮0​0W⊤⋮0​⋯⋯⋱⋯​00⋮W⊤​​

This structure occurs because the outputs from one sample depend only on the inputs from that sample sample (n), and never on other samples in the batch. Therefore, derivatives across different samples are zero. Within each sample, each output neuron is a linear combination of the input features, encoded by W⊤\mathbf{W}^\topW⊤. This highly sparse, block-diagonal structure explains both why the full Jacobian contains many zeros and why we can replace it with a simple matrix multiplication in the backward pass.

Computing ∂L∂W\frac{\partial \mathcal{L}}{\partial \mathbf{W}}∂W∂L​

Having gone trough all steps to compute ∂L∂X\frac{\partial \mathcal{L}}{\partial \mathbf{X}}∂X∂L​, we can now compute ∂L∂W\frac{\partial \mathcal{L}}{\partial \mathbf{W}}∂W∂L​ basically the same, i.e., perform the same core steps. Once again, we already know that the shape of ∂L∂W\frac{\partial \mathcal{L}}{\partial \mathbf{W}}∂W∂L​ must be the same as X\mathbf{X}X as loss L\mathcal{L}L is a scalar values:

X=[w11w12w13w21w22w23]⟹∂L∂W=[∂L∂w11∂L∂w12∂L∂w13∂L∂w21∂L∂w22∂L∂w23]\large \mathbf{X} = \begin{bmatrix} w{11} & w{12} & w{13}\\ w{21} & w{22} & w{23} \end{bmatrix} \quad \Longrightarrow \quad \frac{\partial \mathcal{L}}{\partial \mathbf{W}} = \begin{bmatrix} \frac{\partial\mathcal{L}}{\partial w{11}} & \frac{\partial\mathcal{L}}{\partial w{12}} & \frac{\partial\mathcal{L}}{\partial w{13}}\\ \frac{\partial\mathcal{L}}{\partial w{21}} & \frac{\partial\mathcal{L}}{\partial w{22}} & \frac{\partial\mathcal{L}}{\partial w{23}} \end{bmatrix} X=[w11w21​w12w22​w13w23​]⟹∂W∂L​=[∂w11∂L​∂w21∂L​​∂w12∂L​∂w22∂L​​∂w13∂L​∂w23∂L​​]

Focusing on a single element of this Jacobian matrix, say, ∂L∂w11\frac{\partial \mathcal{L}}{\partial w{11}}∂w11∂L​, we have to consider all possible paths how w11w{11}w11 maye have affected L\mathcal{L}L through any output yiky{ik}yik using the chain rule. Thus, ∂L∂w11\frac{\partial \mathcal{L}}{\partial w{11}}∂w11∂L​ is the sum of all these paths.

∂L∂w11=∑i=1N∑k=1M∂L∂yik∂yik∂w11\large \frac{\partial \mathcal{L}}{\partial w{11}} = \sum{i=1}^N\sum{k=1}^M \frac{\partial\mathcal{L}}{\partial y{ik}}\frac{\partial y{ik}}{\partial w{11}} ∂w11∂L​=∑i=1N∑k=1M∂yik∂L​∂w11∂yik​

But again, we can first simplify this expression since we already know that some partial derivatives ∂yik∂w11\frac{\partial y{ik}}{\partial w{11}}∂w11∂yik​ will be 000. Here, since w11w{11}w11 can only affect the 1st neuron (i.e., k=1), only the partial derivatives ∂yi1∂w11\frac{\partial y{i1}}{\partial w{11}}∂w11∂yi1​ can yield non-zero values. This means that we can get rid of the 2nd sum and fix the value of kkk to 111:

∂L∂w11=∑i=1N∂L∂yi1∂yi1∂w11\large \frac{\partial \mathcal{L}}{\partial w{11}} = \sum{i=1}^N \frac{\partial\mathcal{L}}{\partial y{i1}}\frac{\partial y{i1}}{\partial w{11}} ∂w11∂L​=∑i=1N∂yi1∂L​∂w11∂yi1​

In short, we only sum with respect to the number of samples in the input batch. As before, let's expand the sum just for clarity.

∂L∂w11=∂L∂y11∂y11∂w11+∂L∂y21∂y21∂w11\large \frac{\partial \mathcal{L}}{\partial w{11}} = \frac{\partial\mathcal{L}}{\partial y{11}}\frac{\partial y{11}}{\partial w{11}} + \frac{\partial\mathcal{L}}{\partial y{21}}\frac{\partial y{21}}{\partial w{11}} ∂w11∂L​=∂y11∂L​∂w11∂y11​+∂y21∂L​∂w11∂y21​

To compute the two partial derivates ∂y11∂w11\frac{\partial y{11}}{\partial w{11}}∂w11∂y11​ and ∂y21∂w21\frac{\partial y{21}}{\partial w{21}}∂w21∂y21​, it is useful to look at the definition of Y\mathbf{Y}Y.

Y =[y11y12y13y21y22y23]=[x11w11+x12w21+b1x11w12+x12w22+b2x11w13+x12w23+b3x21w11+x22w21+b1x21w12+x22w22+b2x21w13+x22w23+b3] \begin{align} \large \mathbf{Y}\ &\large= \begin{bmatrix} y{11} & y{12} & y{13}\\ y{21} & y{22} & y{23} \end{bmatrix} = \large \begin{bmatrix} x{11}w{11}+x{12}w{21}+b{1} & x{11}w{12}+x{12}w{22}+b{2} & x{11}w{13}+x{12}w{23}+b{3}\\ x{21}w{11}+x{22}w{21}+b{1} & x{21}w{12}+x{22}w{22}+b{2} & x{21}w{13}+x{22}w{23}+b{3} \end{bmatrix} \end{align} Y ​=[y11y21​y12y22​y13y23​]=[x11w11+x12w21+b1x21w11+x22w21+b1​x11w12+x12w22+b2x21w12+x22w22+b2​x11w13+x12w23+b3x21w13+x22w23+b3​]​​

∂y11∂w11 =∂(x11w11+x12w21+b1)∂w11=x11∂y21∂w11 =∂(x21w11+x22w21+b1)∂w11=x21 \begin{align} \large \frac{\partial y{11}}{\partial w{11}}\ &\large= \frac{\partial (x{11}w{11}+x{12}w{21}+b{1})}{\partial w{11}} = x{11}\\[1em] \large \frac{\partial y{21}}{\partial w{11}}\ &\large= \frac{\partial (x{21}w{11}+x{22}w{21}+b{1})}{\partial w{11}} = x{21} \end{align} ∂w11∂y11​ ∂w11∂y21​ ​=∂w11∂(x11w11+x12w21+b1)​=x11=∂w11∂(x21w11+x22w21+b1)​=x21​​

Performing these steps for all 666 gradients ∂L∂wik\frac{\partial \mathcal{L}}{\partial w{ik}}∂wik∂L​ will gives us the following 666 expressions:

∂L∂w11 =∂L∂y11x11+∂L∂y21x21∂L∂w12 =∂L∂y12x11+∂L∂y22x21∂L∂w13 =∂L∂y13x11+∂L∂y23x21∂L∂w21 =∂L∂y11x12+∂L∂y21x22∂L∂w22 =∂L∂y12x12+∂L∂y22x22∂L∂w23 =∂L∂y13x12+∂L∂y23x22 \begin{align} \large\frac{\partial \mathcal{L}}{\partial w{11}}\ &\large= \frac{\partial\mathcal{L}}{\partial y{11}}x{11} + \frac{\partial\mathcal{L}}{\partial y{21}}x{21}\\[1em] \large\frac{\partial \mathcal{L}}{\partial w{12}}\ &\large= \frac{\partial\mathcal{L}}{\partial y{12}}x{11} + \frac{\partial\mathcal{L}}{\partial y{22}}x{21}\\[1em] \large\frac{\partial \mathcal{L}}{\partial w{13}}\ &\large= \frac{\partial\mathcal{L}}{\partial y{13}}x{11} + \frac{\partial\mathcal{L}}{\partial y{23}}x{21}\\[1em] \large\frac{\partial \mathcal{L}}{\partial w{21}}\ &\large= \frac{\partial\mathcal{L}}{\partial y{11}}x{12} + \frac{\partial\mathcal{L}}{\partial y{21}}x{22}\\[1em] \large\frac{\partial \mathcal{L}}{\partial w{22}}\ &\large= \frac{\partial\mathcal{L}}{\partial y{12}}x{12} + \frac{\partial\mathcal{L}}{\partial y{22}}x{22}\\[1em] \large\frac{\partial \mathcal{L}}{\partial w{23}}\ &\large= \frac{\partial\mathcal{L}}{\partial y{13}}x{12} + \frac{\partial\mathcal{L}}{\partial y{23}}x{22} \end{align} ∂w11∂L​ ∂w12∂L​ ∂w13∂L​ ∂w21∂L​ ∂w22∂L​ ∂w23∂L​ ​=∂y11∂L​x11+∂y21∂L​x21=∂y12∂L​x11+∂y22∂L​x21=∂y13∂L​x11+∂y23∂L​x21=∂y11∂L​x12+∂y21∂L​x22=∂y12∂L​x12+∂y22∂L​x22=∂y13∂L​x12+∂y23∂L​x22​​

We can now rewrite the ∂L∂W\large\frac{\partial \mathcal{L}}{\partial \mathbf{W}}∂W∂L​ by replacing all ∂L∂wik\frac{\partial\mathcal{L}}{\partial w{ik}}∂wik∂L​ with their corresponding solutions.

∂L∂W =[∂L∂w11∂L∂w12∂L∂w13∂L∂w21∂L∂w22∂L∂w23]=[∂L∂y11x11+∂L∂y21x21∂L∂y12x11+∂L∂y22x21∂L∂y13x11+∂L∂y23x21∂L∂y11x12+∂L∂y21x22∂L∂y12x12+∂L∂y22x22∂L∂y13x12+∂L∂y23x22] \begin{align} \large\frac{\partial \mathcal{L}}{\partial \mathbf{W}}\ &\large= \begin{bmatrix} \frac{\partial\mathcal{L}}{\partial w{11}} & \frac{\partial\mathcal{L}}{\partial w{12}} & \frac{\partial\mathcal{L}}{\partial w{13}}\\ \frac{\partial\mathcal{L}}{\partial w{21}} & \frac{\partial\mathcal{L}}{\partial w{22}} & \frac{\partial\mathcal{L}}{\partial w{23}} \end{bmatrix}\\[1em] &\large = \begin{bmatrix} \frac{\partial\mathcal{L}}{\partial y{11}}x{11} + \frac{\partial\mathcal{L}}{\partial y{21}}x{21} & \frac{\partial\mathcal{L}}{\partial y{12}}x{11} + \frac{\partial\mathcal{L}}{\partial y{22}}x{21} & \frac{\partial\mathcal{L}}{\partial y{13}}x{11} + \frac{\partial\mathcal{L}}{\partial y{23}}x{21}\\ \frac{\partial\mathcal{L}}{\partial y{11}}x{12} + \frac{\partial\mathcal{L}}{\partial y{21}}x{22} & \frac{\partial\mathcal{L}}{\partial y{12}}x{12} + \frac{\partial\mathcal{L}}{\partial y{22}}x{22} & \frac{\partial\mathcal{L}}{\partial y{13}}x{12} + \frac{\partial\mathcal{L}}{\partial y{23}}x{22} \end{bmatrix} \end{align} ∂W∂L​ ​=[∂w11∂L​∂w21∂L​​∂w12∂L​∂w22∂L​​∂w13∂L​∂w23∂L​​]=[∂y11∂L​x11+∂y21∂L​x21∂y11∂L​x12+∂y21∂L​x22​∂y12∂L​x11+∂y22∂L​x21∂y12∂L​x12+∂y22∂L​x22​∂y13∂L​x11+∂y23∂L​x21∂y13∂L​x12+∂y23∂L​x22​]​​

Last, we can again decompose this Jacobian into a product of two matrices, the transpose of input matrix X\mathbf{X}X and the upstream gradient ∂L∂w11\frac{\partial\mathcal{L}}{\partial w{11}}∂w11∂L​:

∂L∂W =[x11x21x12x22][∂L∂y11∂L∂y12∂L∂y13∂L∂y21∂L∂y22∂L∂y23]=X⊤∂L∂Y \begin{align} \large\frac{\partial \mathcal{L}}{\partial \mathbf{W}}\ &\large= \begin{bmatrix} x{11} & x{21} \\ x{12} & x{22} \end{bmatrix} \begin{bmatrix} \frac{\partial\mathcal{L}}{\partial y{11}} & \frac{\partial\mathcal{L}}{\partial y{12}} & \frac{\partial\mathcal{L}}{\partial y{13}}\\ \frac{\partial\mathcal{L}}{\partial y{21}} & \frac{\partial\mathcal{L}}{\partial y{22}} & \frac{\partial\mathcal{L}}{\partial y{23}} \end{bmatrix}\\[1em] &\large = \mathbf{X}^\top \frac{\partial\mathcal{L}}{\partial\mathbf{Y}} \end{align} ∂W∂L​ ​=[x11x12​x21x22​][∂y11∂L​∂y21∂L​​∂y12∂L​∂y22∂L​​∂y13∂L​∂y23∂L​​]=X⊤∂Y∂L​​​

This solution shows that the linear layer needs to store X\mathbf{X}X for the backward pass. In other words, the memory footprint of a linear layer — at least during training — is not just determined by its weights and biases but also by its input from the previous layer. As the shape of input matrix X\mathbf{X}X is N×DN\times DN×D, it is easy to see that the batch size NNN becomes an important factor affecting the overall memory requirements for training a neural network.

Side note: Notice that we once more avoided to compute the full Jacobian matrix ∂L∂W\frac{\partial \mathcal{L}}{\partial \mathbf{W}}∂W∂L​ which has the following form:

∂Y∂W=[X0⋯00X⋯0⋮⋮⋱⋮00⋯X]\large \frac{\partial \mathbf{Y}}{\partial \mathbf{W}} = \begin{bmatrix} X & 0 & \cdots & 0 \\ 0 & X & \cdots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \cdots & X \end{bmatrix} ∂W∂Y​=​X0⋮0​0X⋮0​⋯⋯⋱⋯​00⋮X​​

However, like for ∂L∂W\frac{\partial \mathcal{L}}{\partial \mathbf{W}}∂W∂L​, the block-diagonal structure and each block corresponding to the input matrix X\mathbf{X}X allows avoiding the computation of the full Jacobian matrix as the "simply" solution for ∂Y∂W\frac{\partial \mathbf{Y}}{\partial \mathbf{W}}∂W∂Y​ yields the same result.

Computing ∂L∂b\frac{\partial \mathcal{L}}{\partial \mathbf{b}}∂b∂L​

The last remaining gradient we need to compute is ∂L∂b\frac{\partial \mathcal{L}}{\partial \mathbf{b}}∂b∂L​, but the steps to accomplish this are the same. Knowing the shape of bias vector b\mathbf{b}b, we also know the shape of the Jacobian matrix ∂L∂b\frac{\partial \mathcal{L}}{\partial \mathbf{b}}∂b∂L​.

b=[b1b2b3]⟹∂L∂b=[∂L∂b1∂L∂b2∂L∂b3]\large \mathbf{b} = \begin{bmatrix} b{1} & b{2} & b{3} \end{bmatrix} \quad \Longrightarrow \quad \frac{\partial \mathcal{L}}{\partial \mathbf{b}} = \begin{bmatrix} \frac{\partial\mathcal{L}}{\partial b{1}} & \frac{\partial\mathcal{L}}{\partial b{2}} & \frac{\partial\mathcal{L}}{\partial b{3}} \end{bmatrix} b=[b1​b2​b3​]⟹∂b∂L​=[∂b1∂L​​∂b2∂L​​∂b3∂L​​]

Let's consider an individual entry, say, ∂L∂b1\frac{\partial\mathcal{L}}{\partial b{1}}∂b1∂L​. Its value, in principle, depends on all paths b1b1b1 may affect the value of L\mathcal{L}L, which can be determined using the chain rule. Thus, ∂L∂b1\frac{\partial\mathcal{L}}{\partial b{1}}∂b1∂L​ is the sum of all these possible paths.

∂L∂b1=∑i=1N∑j=1M∂L∂yij∂yij∂b1\large \frac{\partial \mathcal{L}}{\partial b{1}} = \sum{i=1}^N\sum{j=1}^M \frac{\partial\mathcal{L}}{\partial y{ij}}\frac{\partial y{ij}}{\partial b{1}} ∂b1∂L​=∑i=1N∑j=1M∂yij∂L​∂b1∂yij​

Like for ∂L∂w11\frac{\partial \mathcal{L}}{\partial w{11}}∂w11∂L​, we know that b1b1b1 can only affect the output values yi1y{i1}yi1 of the 1st neuron. This allows us to simplify the expression by removing the 2nd sum, fix the value of kkk to 111, and sum only with respect to the number of samples NNN in the input batch.

∂L∂b1=∑i=1N∂L∂yi1∂yi1∂b1\large \frac{\partial \mathcal{L}}{\partial b{1}} = \sum{i=1}^{N} \frac{\partial\mathcal{L}}{\partial y{i1}}\frac{\partial y{i1}}{\partial b{1}} ∂b1∂L​=∑i=1N∂yi1∂L​∂b1∂yi1​

By expanding this sum, we can quickly see which partial derivatives we need to compute.

Basic Linear Layer Class

In deep learning frameworks such as PyTorch or Tensorflow, layers are typically implemented as classes with explicit forward() and backward() methods because this structure mirrors both the mathematical definition of the layer and the way neural networks are trained. In case of a linear layer, the forward() method encapsulates the computation Y=XW+b\mathbf{Y} = \mathbf{X}\mathbf{W} + \mathbf{b}Y=XW+b, producing outputs from inputs, while the backward() method is responsible for computing gradients with respect to the inputs and parameters. Grouping these operations inside a single class makes the layer a self-contained computational unit that can be easily composed with other layers to form a full network, reflecting the modular nature of neural network architectures.

Crucially, the class must also store all intermediate data required for the backward pass, such as the input \matrixX\matrix{X}\matrixX from the forward computation. During training, gradients flow backward through the network, and computing the gradient ∂L∂W\frac{\partial \mathcal{L}}{\partial \mathbf{W}}∂W∂L​ depends directly on values seen in the forward pass. By caching this information inside the layer object, the backward method can compute gradients efficiently without recomputing the forward pass or constructing large Jacobian matrices. This design not only improves computational efficiency but also makes the implementation closely align with the principles of backpropagation used in modern deep learning frameworks.

The code cell below shows the class Linear which represents a basic implementation of a linear layer. All the computations done in the forward() and backward() method, we have already seen above when computing the output and all gradients individually. The only additional consideration is the initialization of the weights W\mathbf{W}W and biases b\mathbf{b}b.

class Linear:

    def __init__(self, in_features, out_features):
        # Weight initialization (simple Gaussian)
        self.W = np.random.randn(in_features, out_features) * 0.01
        self.b = np.zeros(out_features)

        # Gradients
        self.dW = np.zeros_like(self.W)
        self.db = np.zeros_like(self.b)

        # Cache for backward pass
        self.X = None

    def forward(self, X):
        self.X = X
        return X @ self.W + self.b

    def backward(self, dY):
        self.dW = self.X.T @ dY  # Gradient w.r.t. weights
        self.db = dY.sum(axis=0) # Gradient w.r.t. bias
        return dY @ self.W.T     # Gradient w.r.t. input
